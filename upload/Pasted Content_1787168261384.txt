# 20. STRIPE — REQUISITO CRÍTICO

Implementar Stripe corretamente.

Na primeira fase:

**STRIPE TEST MODE**

Nunca colocar secret key no frontend.

Nunca criar valores de pagamento com base no preço recebido diretamente do browser.

O browser envia APENAS:

```json
{
  "items": [
    {
      "sku": "LT-OIL-RES-500",
      "quantity": 2
    }
  ],
  "customerType": "B2C"
}
```

O servidor:

1. procura o SKU no catálogo server-side;
2. confirma que existe;
3. confirma preço;
4. confirma quantidade;
5. confirma disponibilidade;
6. identifica se contém álcool;
7. calcula shipping;
8. cria os Stripe line_items;
9. cria a Checkout Session.

A autoridade do preço é SEMPRE server-side.
